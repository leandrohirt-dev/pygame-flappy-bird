# Flappy Bird em Pygame

Jogo em Python e Pygame mostrado no vídeo **Flappy Bird**. Aperte espaço
para fazer o pássaro subir, passe pelos canos e marque pontos. Ao bater em
um cano ou sair da tela, o jogo recomeça e a pontuação volta a zero.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python flappy_bird.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Use **espaço** para subir. Feche a janela para sair.

## Código passo a passo

O arquivo `flappy_bird.py` contém o jogo completo. A pasta `passos/` mostra
as quatro versões executáveis apresentadas no vídeo: pássaro, canos,
colisão e pontuação.

O pássaro é desenhado com um emoji da fonte do sistema. Em computadores
sem uma fonte de emoji compatível, ele pode aparecer de outra forma.
